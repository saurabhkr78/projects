# EventHub

## Vision

EventHub is a multi-tenant SaaS platform that enables organizations to create, manage, and sell tickets for events.

Unlike a traditional ticket booking website, EventHub provides businesses with the tools required to organize events, manage venues, configure seat layouts, publish tickets, and analyze sales, while customers can discover events and securely purchase tickets.

The project is designed as a production-grade backend system and will evolve incrementally from a monolithic application to a distributed system.

## Product Goals

- Build a scalable event management platform.
- Prevent duplicate seat bookings.
- Support multiple organizations.
- Provide analytics for organizers.
- Deliver a production-ready backend architecture.

## Engineering Goals

This project is also an engineering journey.

Throughout the development process the system will gradually introduce:

- PostgreSQL
- SQL
- pgx
- Clean Architecture
- Interfaces
- Transactions
- Query Optimization
- Redis
- Kafka
- gRPC
- Docker
- CI/CD
- AWS

Each technology will be introduced only when a real business requirement justifies its use.
